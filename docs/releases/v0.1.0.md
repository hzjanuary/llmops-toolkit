# v0.1.0 — Initial RAGOps Harness Source Preview

GitHub pre-release; source ZIP and tar.gz generated by GitHub only. The actual
release page/tag/commit and verification records establish publication status.
No binaries, prebuilt executables, packages, Docker images or deployments.

RAGOps Harness is a local-first Rust/Tokio/Axum/Reqwest CLI toolkit for a bounded
non-streaming OpenAI Chat Completions proxy, SQLite FinOps telemetry, operational
terminal monitoring, reproducible offline RAG evaluation and explicitly scoped
safety-response heuristics. It is not a RAG engine, general gateway or agent OS.

The proxy defaults to loopback and disabled forwarding. Billable forwarding
requires separate owner/provider credentials, explicit models and cost policy;
request/response bytes, output tokens, concurrency, deadlines, attempts and
estimated cost reservations are bounded. Provider errors are redacted. SQLite
receipts distinguish pending, failed and indeterminate work; unknown usage/price
is null. Existing data and migrations 1/2 are preserved; backup refuses overwrite.
TTY/headless monitoring and SIGINT/SIGTERM shutdown are tested with synthetic data.

Default evaluation is a deterministic lexical heuristic, not ground-truth
faithfulness. Default scanning uses offline fixtures and refusal-marker signals,
not vulnerability or safety certification. Live judging requires explicit privacy
consent, reviewed provider/model/pricing and bounds. Live targets require exact
authorization and destination/resource limits. No live OpenAI compatibility,
independent security certification, real inference or external target scan is
claimed by this release's offline evidence. Streaming is not supported.

Tested platform: Linux x86_64, Rust 1.99.0, Python 3.12+. Initial crate/tool/advisory
fetch needs network; runtime tests use only loopback mocks and synthetic temporary
databases. Local/remote verification includes format, strict Clippy, 28 ordinary
tests plus an explicitly run fixture helper, authenticated proxy -> mock -> SQLite
-> real TUI, migration/concurrency/backup, full reachable-history/tree Gitleaks,
RustSec vulnerability/unsoundness checks for all retained lockfiles, installed
MIT/dependency inventory, exact source archives, tamper rejection and clean builds.
Exact reviewed source/merge SHA, CI runs, artifact digests and observed public
archive checksums are appended to the actual release notes after verification.

Limitations: estimates are not invoices; process restart resets budgets and
unknown-price opt-in waives a USD guarantee. Provider account caps remain needed.
The listener has no built-in TLS or global TCP connection cap. Metadata can reveal
activity; protect databases, sidecars and backups. SIGKILL/power loss cannot
restore terminal state. Windows/macOS and a lower MSRV are unverified. No paid or
live validation is implied by a mock PASS. GitHub archive compression bytes can
change; the exact commit and per-file content manifest bind reviewed source.

Main rulesets remain owner-decision proposals; no setting is silently applied or
bypassed. Separate canonical Harness maintenance may begin only after this
pre-release is public and both public source archives have been verified; its
result must be reported separately and never assumed from this publication.
