# Design and scope

No application refactor. Preserve current secure Rust architecture, resource and
cost policies, nullable FinOps estimates, additive migrations, offline heuristics
and authorized live gates. Provenance records use the explicit owner declaration
and file hashes/first local appearances, never usernames as copyright authority.

Project license, dependency obligations and historical workflow lineage remain
separate. Generic workflow wording is not claimed independently authored merely
from first appearance or from the repository owner's use of that environment.
The obsolete URL-based external ownership assumption is withdrawn without
rewriting historical evidence or denying genuine third-party rights.

Release is source-only. Final source SHA must be tested remotely; actual merge
commit and annotated tag target must be checked after the normal merge. Archive
verification accounts for GitHub source archive prefixes and compares every file
against the reviewed Git tree. Do not confuse a synthetic PR merge ref with a
completed merge. Canonical Harness cleanup is a later separate workspace/task.
