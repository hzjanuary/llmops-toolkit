# LLMOps Toolkit technical stories

Product feature records under epics/ explain the proxy/FinOps, evaluation,
safety-response heuristics and terminal monitor. Their original requirements
and validation history are preserved, including superseded unsafe behavior;
current docs/product contracts and executable tests govern current operation.

- [REBRAND-001](initiatives/REBRAND-001/overview.md): current identity, compatible
  environment aliases and audited development-scaffolding retirement.
- [SPEC-001](initiatives/SPEC-001/overview.md): historical secure source refactor.
- [OSS-001](initiatives/OSS-001-publication/overview.md): historical ownership,
  MIT installation and source-preview publication work.

New product work should state the affected contract, bounded change and exact
verification evidence. See [development](../DEVELOPMENT.md),
[maintenance](../MAINTENANCE.md) and [test matrix](../TEST_MATRIX.md).
No generic workflow template package or external bootstrap is required.
